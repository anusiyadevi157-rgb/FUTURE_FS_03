# AURA Boutique

A modern and responsive local business website designed for AURA Boutique.

## About the Project

AURA Boutique is a fashion boutique website created to showcase elegant sarees, ethnic wear and modern fashion collections.

The website provides customers with an attractive online presence where they can explore collections, learn about the boutique and get in touch easily.

## Features

- Responsive design for desktop and mobile
- Elegant hero section
- Fashion collections
- About section
- Style gallery
- Customer testimonials
- Contact and enquiry form
- WhatsApp contact button
- Call button
- Smooth scrolling navigation
- Mobile navigation menu
- Scroll-to-top button
- Modern animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
